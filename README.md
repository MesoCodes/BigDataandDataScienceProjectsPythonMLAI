# BigDataandDataScienceProjectsPythonMLAI
Projects that were done in CSCE 5300 at UNT (Introduction to Big Data and Data Science). Introductory Python ML/AI course.

Assignment 1: This was the first project of the course. We worked on basic Python fundamentals like selecting portions of strings, identifying the classes of data, using the math package, for loops, and if else statements.

Assignment 2: Used matplotlib and numpy to organize data into graphs (bar chart and 3D plot).

Assignment 3 (and A3Part2): Used pandas to examine dataset and extract different categories of values. Used pyspark create dataframe and filter data.

Assignment 4 (A4): Used numpy and matplotlib to do polynomial regression.

Assignment 5 (A5P1, A5P2): Used matplotlib to plot ROC curve and pytorch to train with MNIST dataset.

Assignment 6 (A6): Training dataset to make predictions with k nearest neighbors and numpy.

Assignment 7 (A7): Practice with basic manipulation of strings in Python with filter function, len, map, and more.

Assignment 8 (A8): Used joblib and for loops to print square of all positive prime numbers, with the range of the squared values being between 2 and 100,000, exclusive. Used mpi4py to communicate the rank and size of the process.
